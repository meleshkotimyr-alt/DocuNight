# DocuNight — сборка ZIP для Windows без установки Python на вашем компьютере

Этот архив содержит исходный код приложения и готовый workflow, который собирает Windows-приложение в облаке GitHub Actions. Вам НЕ нужно устанавливать Python на свой компьютер, чтобы получить собранный ZIP, но один раз нужно загрузить этот проект в свой GitHub-репозиторий.

## Получить готовый ZIP

1. Войдите на https://github.com/ и создайте новый репозиторий, например `DocuNight`.
2. Распакуйте этот архив на компьютере.
3. Загрузите в репозиторий все файлы и папку `.github` из архива. Важно: включите скрытую папку `.github`.
   - Самый простой вариант: в репозитории нажмите **Add file → Upload files**, перетащите файлы и папку `.github` и нажмите **Commit changes**.
   - Если веб-интерфейс не позволяет загрузить скрытую папку, используйте GitHub Desktop или GitHub веб-интерфейс для создания файла `.github/workflows/windows-build.yml` с содержимым из архива.
4. Откройте вкладку **Actions** в репозитории.
5. Выберите **Build DocuNight for Windows** и нажмите **Run workflow** (если workflow уже запустился автоматически после загрузки, откройте последний успешный запуск).
6. Дождитесь зелёной галочки, откройте запуск и внизу раздел **Artifacts**.
7. Скачайте **DocuNight-Windows-x64** — это ZIP с готовой программой. Распакуйте его и запускайте `DocuNight.exe`. Python на компьютере не нужен.

## Что внутри
- `main.py` — приложение.
- `requirements.txt` — библиотеки, которые установит облачный сборщик.
- `.github/workflows/windows-build.yml` — автоматическая сборка Windows ZIP.

## Честное уточнение
Этот workflow создаёт папку приложения PyInstaller с EXE и сопутствующими файлами, упакованную в ZIP. Это надёжнее для Qt-приложений, чем пытаться упаковать всё в один EXE. Я не могу приложить уже скомпилированный Windows EXE прямо из этой Linux-среды: для корректной сборки нужен Windows runner. После первого облачного запуска готовый ZIP можно скачивать из раздела Artifacts.
